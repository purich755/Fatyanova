# Продюсерский центр Анны Фатьяновой — демо главной

Демо для холодной продажи. Концепция — **«Программка гала-концерта»**: третий звонок → занавес → номера программы → антракт → поклон, занавес закрывается. Две фактуры чередуются: тёмная «сцена» и светлая «бумага программки». Сквозная деталь — розовая атласная лента, в финале она завязывается бантом над контактами.

## Запуск

```bash
npm install
npm run dev        # http://localhost:8650
npm run build      # статический экспорт в out/
npm start          # раздаёт out/ на http://localhost:8651
```

Проверки:

```bash
npm test                                   # 55 клик-тестов: десктоп, 390 px, reduced-motion
node tools/tour.mjs 1440 900               # скриншот-тур в raw/tour-1440/ (также 390, 768, --reduced)
sh tools/lh.sh                             # Lighthouse mobile против out/ на 8651
```

Медиа и шрифты пересобираются скриптами: `npm run media`, `node scripts/subset-fonts.mjs`, `node scripts/build-signature.mjs`.

Стек: Next.js 15 (App Router, `output: 'export'`) + TypeScript, чистый CSS с переменными (`app/globals.css`, `app/sections.css`), GSAP 3.15 (ScrollTrigger, SplitText, Flip) и Lenis. Все факты и подписи — в `lib/data.ts`.

## Что сделано по разделам

| № | Раздел | Что происходит |
|---|---|---|
| 00 | Третий звонок | Три точки загораются по очереди, затем сливаются в полоску рампы. Показывается один раз за сессию, есть «Пропустить». |
| 01 | Занавес | Бархат нарисован CSS-складками. После звонка он собирается к кулисам. Под ним медленный Ken Burns по двум кадрам, луч прожектора за курсором (на тач-экранах гуляет сам) и бегущая строка площадок. |
| 02 | Программа вечера | Лист наезжает на закреплённую сцену. Оглавление с отточиями работает как навигация. |
| 03 | Слово продюсера | Цитата курсивом, текст от первого лица, подпись Marck Script прописывается линией. Портрет в паспарту. |
| 04 | Путь на большую сцену | На десктопе секция закреплена: поднимаются пять ступеней-подиумов, работает счётчик «Ступень 3 / 5». На мобильных — вертикальная лестница. |
| — | Лента | Атласная лента с перекрутами рисуется по скроллу. |
| 05 | Из Сибири с любовью | Кадры сменяются по скроллу. Два «билетика» переключают программы, апрельский на секунду зажигает звёзды. |
| 06 | Танцуем со звёздами | Созвездие из пяти имён. Наведение, фокус или нажатие открывает карточку-программку. На мобильных — свайп по карточкам и мини-созвездие. |
| 07 | Что мы делаем | Строки программы. На десктопе за курсором плывёт фото, на тач-экранах строка раскрывается аккордеоном. |
| 08 | Закулисье и сцена | Плёнка с перфорацией: тянется мышью с инерцией, листается колесом. Лупа 2×, фильтры (Flip), лайтбокс с FLIP-переходом, стрелками, свайпом и Esc. Блок «30 секунд со сцены» — три клипа. |
| 09 | Антракт | Три шага и кнопка связи, без форм. |
| 10 | Поклон | По скроллу занавес сходится. В центре контакты, над ними завязывается бант. |

`prefers-reduced-motion`: прелоадера нет, занавес сразу открыт, пинов, частиц, луча и автоплея видео нет.

## Качество

- **Lighthouse mobile** (прод-сборка, localhost): Performance 87, Accessibility 100, Best Practices 100. SEO 63 — только из-за `robots: noindex`: демо закрыто от поиска, для боевой версии убрать в `app/layout.tsx`. LCP — первый кадр сцены (AVIF с preload), CLS 0,012.
- **Что подняло Performance с 77:**
  - сабсет шрифтов вместо гугловских подмножеств: 8 файлов по ~175 КБ превратились в 2 сразу нужных (~54 КБ);
  - отказ от blur-заглушек next/image — минус ~50 КБ HTML;
  - ленивые постеры видео;
  - второй кадр hero грузится после `load`.
- **Адаптив:** проверен на 360, 390, 768, 1440, без горизонтального скролла. Ширина 1920 укладывается в контейнер 1320 px.
- **Грабли.** `locator.click()` в Playwright сам докручивает страницу и спорит с Lenis. В тестах кликать `page.mouse.click` по координатам: на якорях тест падал, а у живого пользователя всё работало.
